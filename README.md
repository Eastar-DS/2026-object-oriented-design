## 🔄 진행 방식

📣 **스터디는 매주 금요일 14:00에 진행됩니다.** 📣

매주 1개의 장을 읽고, 아래 내용을 남깁니다.

| 무엇을                  | 어디에       | 언제까지                   |
| ----------------------- | ------------ | -------------------------- |
| 학습한 내용 정리        | Pull Request | 스터디 시작 전까지         |
| 각자 얻은 인사이트      | Issue 코멘트 | 스터디 종료 후 일주일 이내 |
| 함께 논의하고 싶은 질문 | Discussion   | 자유 (필수 아님)           |

<br/>

### Pull Request — 학습 내용 정리

- 해당 장에서 **학습한 내용 + 프론트엔드 관점에서의 적용**을 정리해 PR로 올립니다.
- 정리 형식은 자유입니다.
- PR 제목에는 **정리한 글의 제목과 본인 닉네임**만 적습니다.
- PR에는 해당 장의 **label** 과 본인 **assignee** 를 지정합니다.
- **최소 3명의 승인** 을 받아야 머지할 수 있습니다.

<br/>

### Issue — 인사이트 요약

- 매 주차마다 Issue를 **하나** 생성합니다.
- Issue에는 해당 장의 **label** 과 **스터디원 전체** 를 assignee로 지정합니다.
- 스터디가 끝난 뒤, 각자 얻은 인사이트를 **코멘트로** 남깁니다.
- 스터디 이후 **일주일 이내** 에 1개 이상의 코멘트를 작성합니다.

<br/>

### Discussion — 자유로운 질문 & 토의

- 책을 읽다가 **함께 논의하고 싶은 질문**이 생기면 Discussion에 편하게 남겨주세요.
- 제목은 질문 내용을 그대로 적고, 해당 장의 **label** 로 구분합니다.
- 글을 올릴 때 내용에 맞는 **카테고리**를 선택해주세요.
- 등록 시점이나 개수에 정해진 규칙은 없습니다.
- 다른 사람의 질문에 코멘트를 달거나, 스터디 시간에 함께 얘기 나눠도 좋습니다.

| 카테고리         | 이럴 때 사용해요                                                     |
| ---------------- | -------------------------------------------------------------------- |
| 🤔 A vs B        | 정답을 고르기 어려운 문제나 고민이 있으신가요? 장/단점을 비교하며 함께 결정해봐요. |
| ❓ Ask           | 궁금했던 부분이 있으신가요? 자유롭게 질문해봐요.                     |
| 👃 Code Smell    | 나중에.. 라는 말과 함께 방치된 코드들이 있나요? 함께 정답을 찾아가봐요. |
| 💬 General       | 함께 논의하고 싶은 내용을 자유롭게 올려보세요.                       |

<br/>

## 컨벤션

- **Discussion과 PR은 label로 장을 구분**하므로 제목에 `[N장]` 말머리를 붙이지 않습니다.
- `장 제목` 자리에는 **책 목차에 적힌 장 제목을 그대로** 씁니다.
- `{크루명}` 자리에는 **본인 닉네임**을 씁니다. (예: `유월`)
- PR 제목과 정리 파일명의 `제목`은 **자유롭게** 정합니다. (정리한 글의 제목)
- 커밋 메시지의 `작업 내용` 자리에는 **그 커밋에서 한 일**을 씁니다. (예: `학습 내용 정리`, `오타 수정`)

| 항목            | 형식                         | 예시                                          |
| --------------- | ---------------------------- | --------------------------------------------- |
| Discussion 제목 | `질문 내용?`                 | `설계는 언제부터 고민해야 할까요?`            |
| PR 제목         | `제목 - {크루명}`            | `리액트의 상태 끌어올리기의 역설 - {크루명}`  |
| Issue 제목      | `[N장] 장 제목`              | `[1장] 객체, 설계`                            |
| 커밋 메시지     | `[N장] 작업 내용 - {크루명}` | `[1장] 학습 내용 정리 - {크루명}`             |
| 학습 내용 정리 파일명     | `제목_{크루명}.md`           | `리액트의 상태 끌어올리기의 역설_{크루명}.md` |
